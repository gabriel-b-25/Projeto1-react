# Projeto 1: Portfolio

Página de perfil pessoal desenvolvida com **React + TypeScript + Vite** e estilizada com **Tailwind CSS**.

## Para rodar o projeto:

Pré-requisito: ter o [Node.js](https://nodejs.org/) instalado.

Digite no terminal:
1) Instale as dependências: npm install
2) Inicie o servidor de desenvolvimento: npm run dev
Acesse o link gerado no terminal.

## Sobre o projeto
A página apresenta um perfil com as seguintes seções, cada uma implementada como um componente React:

| Componente | Descrição |
|---|---|
| `Cabecalho` | Foto, nome, curso e período |
| `Sobre` | Painel com texto de apresentação (usa `children`) |
| `Habilidades` | Lista de habilidades com nível |
| `Projetos` | Cards de projetos com situação (em andamento/concluído) e link opcional |
| `Contato` | Nome, e-mail e rede social |
| `Rodape` | Instituição, curso, disciplina e ano |
```
